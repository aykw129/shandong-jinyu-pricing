# 山东金宇9月调价对比

公开页面：https://aykw129.github.io/shandong-jinyu-pricing/

基于用户提供的《山东金宇9月电价调整.xlsx》与24小时9月最终到户电价H+Q。涵盖6个场站、10个收费区间、50组原时段价差，并逐小时比较到户电费成本。

支持选择周边场站、调整策略、手动修改收费区间总价、查看成本对比曲线及24小时成本价差明细、导出当前调整后价格数据。修改后复制浏览器完整地址，可分享同一调整后价格。

## 成本比较口径

原价对成本价差＝金宇原总价−同小时到户成本。调整后价格对成本价差＝当前调整后价格总价−同小时到户成本。正值表示高于成本参考，负值表示低于成本参考。成本原值保留8位小数，计算保留完整精度，页面价差显示4位。到户成本作为参考，不替换原对外收费电价，不自动改变现有定价策略。

默认只降不涨、匹配周边最低总价。其全天单时均价为0.7754166667元/度；到户成本单时均价为0.84061875元/度；价差为−0.0652020833元/度。原总价有11小时、默认调整后价格有21小时低于到户成本参考。均价按时长加权，不按充电电量加权；差额不等同于净利润，尚未计入损耗、租金、运维、折旧、税费等。

周边价差＝金宇价格−周边场站同小时价格。正值为金宇更贵。按原表实际开始/结束时间对齐；23:59末段延至24:00。价格单位按元/度解释。数据为用户提供的9月价格快照，未说明年份、采价日期、精确距离或充电量。页面操作只改变模拟调整后价格，不会修改实际场站价格。

## 页面文件

index.html 为加载入口，payload-<SHA256>-<分段号>.txt 为对应完整页面的压缩内容。打开网站时自动还原并校验SHA-256，保留完整数据及交互。GitHub Pages 从 main 的 /(root) 发布，使用 .nojekyll。历史压缩分段保留以兼容缓存。

离线使用单文件《山东金宇9月调价对比.html》。导出CSV按24小时与当前选择的周边场站展开，全部5个场站选中时共120行。
